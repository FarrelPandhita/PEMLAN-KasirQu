# IDE Setup Guide: Visual Studio Code

This document provides a dedicated, step-by-step setup for developers using Visual Studio Code (VSCode) as their primary backend development environment.

## 1. Required Installations
Before opening the project, ensure you have the following installed on your system:
- **Java Development Kit (JDK) 17+**
- **Apache Maven** (Optional, VSCode includes an embedded wrapper, but system-wide is better)
- **Git**

## 2. VSCode Extensions
Install the following extensions from the marketplace:
- **Extension Pack for Java** (Publisher: Microsoft) - Essential for code completion, debugging, and Maven support.
- **MySQL** (Publisher: Weijan Chen) or **Database Client** - Useful for viewing the local database directly in the IDE.
- **DotENV** (Publisher: mikestead) - For syntax highlighting the `.env` file.

## 3. Opening the Project
1. Open VSCode.
2. Select `File` > `Open Folder...`
3. Navigate to the `PEMLAN-KasirQu` folder and open it.
4. On the bottom right, you will see a prompt from the Java extension saying "Importing Java project". Wait for this to complete. 
5. The `pom.xml` defines the project structure. VSCode will automatically download the required dependencies (like `mysql-connector-j`).

## 4. Environment Variables
1. Duplicate the `.env.example` file and rename it to `.env`.
2. Update the credentials to match your local MySQL server.
*(Note: Ensure your Java code utilizes a `.env` loader library like `java-dotenv` to parse this file, as configured in the project).*

## 5. Running the Application
To run the application, navigate to the main entry point class (usually located in `src/main/java/com/kasirqu/gui/main/` or similar).
- Click the "Run" lens that appears above the `public static void main(String[] args)` method.
- Alternatively, open the terminal in VSCode (`Ctrl+~`) and run: `mvn clean compile exec:java`.

## Warning
**DO NOT** edit the `.java` files that correspond to GUI forms if they were generated by NetBeans Matisse. Doing so will desynchronize the `.form` file and break the UI for the NetBeans developer.
